= Playground 및 MCP 연결

이 모듈에서는 앞에서 MaaS로 서비스한 모델을 Playground에 연결하고, 학과 교육과정을 조회하는 MCP(Model Context Protocol) 서버를 도구로 추가합니다. 모델이 학습하지 않은 정보도 외부 도구를 호출해 정확하게 답하는 과정을 직접 확인합니다.

이 모듈을 완료하면 다음을 갖추게 됩니다:

* Playground에 연결된 MaaS 모델
* 학과 교육과정을 조회하는 MCP 도구가 연결된 에이전트
* MCP 도구 사용 전후의 답변 차이에 대한 이해

== 단계 7.1: MCP 서버 배포
:mcp-namespace: mcp-servers

== 단계 7.2: MCP 서버 배포

학과 교육과정을 조회하는 MCP 서버를 클러스터에 배포합니다. 이 서버는 교육과정 데이터(61개 과목)를 읽어 다음 세 가지 도구를 제공합니다.

[cols="1,2,2",options="header"]
|===
| 도구 | 기능 | 인자

| `search_courses`
| 과목명(국문/영문)으로 과목 검색
| `keyword`

| `list_courses`
| 학년·학기·이수구분 조건으로 과목 목록 조회
| `grade`, `semester`, `category` (모두 선택)

| `credit_summary`
| 이수구분별 과목 수와 학점 합계 집계
| `grade`, `semester` (모두 선택)
|===

배포 파일(`curriculum-mcp.yaml`)에는 다음 세 가지 리소스가 들어 있습니다.

* *ConfigMap* (`curriculum-mcp-src`): MCP 서버 코드(`server.py`)와 교육과정 데이터(`courses.json`)
* *Deployment* (`curriculum-mcp`): Python 컨테이너에서 MCP 서버를 실행
* *Service* (`curriculum-mcp`): 클러스터 내부에서 `8000` 포트로 서버에 접근하는 주소

* `@mcp.tool()` 데코레이터가 함수를 MCP 도구로 등록합니다. 함수의 타입 힌트(`keyword: str`)가 도구의 입력 형식이 됩니다.
* *docstring이 곧 모델에게 주는 설명서*입니다. 모델은 이 설명을 읽고 언제, 어떤 인자로 도구를 호출할지 결정합니다.

=== 프로젝트 생성 및 배포

. OpenShift Console 상단의 *WebTerminal* 아이콘(`>_`)을 클릭하여 터미널을 엽니다.
. MCP 서버를 배포할 프로젝트를 만듭니다.
+
[source,bash,subs="attributes"]
----
oc new-project {mcp-namespace}
----

. 아래 블록 오른쪽 위의 복사 버튼을 클릭하여 전체 내용을 복사한 뒤, WebTerminal에 붙여넣고 `Enter`를 누릅니다. `curriculum-mcp.yaml` 파일이 생성됩니다.
+
[%collapsible]
.curriculum-mcp.yaml 생성 명령 (클릭하여 펼치기)
====
[source,bash]
----
cat > curriculum-mcp.yaml <<'EOF'
# 인공지능공학전공 교육과정 조회 MCP 서버
# 사용법: oc apply -f curriculum-mcp.yaml -n <본인-네임스페이스>
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: curriculum-mcp-src
  labels:
    app: curriculum-mcp
data:
  server.py: |
    """인공지능공학전공 교육과정 조회 MCP 서버 (Streamable HTTP)."""
    import json
    import os
    from collections import defaultdict

    from mcp.server.mcpserver import MCPServer
    from mcp.server.transport_security import TransportSecuritySettings

    DATA_FILE = os.environ.get("COURSES_FILE", os.path.join(os.path.dirname(__file__), "courses.json"))
    with open(DATA_FILE, encoding="utf-8") as f:
        COURSES = json.load(f)

    CATEGORIES = sorted({c["category"] for c in COURSES})

    mcp = MCPServer(
        name="curriculum",
        instructions=(
            "조선대학교 AI소프트웨어학부 인공지능공학전공의 교육과정(학년/학기별 개설 과목, 이수구분, 학점, "
            "강의·실습 시간)을 조회하는 도구입니다. 교육과정에 관한 질문은 추측하지 말고 이 도구로 확인하세요."
        ),
    )


    def _num(x: float) -> str:
        return str(int(x)) if x == int(x) else str(x)


    def _fmt(c: dict) -> str:
        return (f"- {c['grade']}학년 {c['semester']}학기 | {c['category']} | {c['name_ko']} ({c['name_en']}) | "
                f"{_num(c['credits'])}학점 | 강의 {_num(c['lecture_hours'])}시간, 실습 {_num(c['practice_hours'])}시간")


    def _norm(s: str) -> str:
        return "".join(s.split()).lower()


    @mcp.tool()
    def search_courses(keyword: str) -> str:
        """과목명(국문 또는 영문)에 키워드가 포함된 과목을 찾습니다.
        과목이 몇 학년 몇 학기에 개설되는지, 몇 학점인지, 이수구분이 무엇인지 확인할 때 사용합니다.

        Args:
            keyword: 찾을 과목명 또는 그 일부 (예: "딥러닝", "클라우드", "machine learning")
        """
        k = _norm(keyword)
        hits = [c for c in COURSES if k in _norm(c["name_ko"]) or k in _norm(c["name_en"])]
        if not hits:
            return f"'{keyword}'(이)가 포함된 과목이 교육과정에 없습니다."
        return f"'{keyword}' 검색 결과 {len(hits)}개 과목:\n" + "\n".join(_fmt(c) for c in hits)


    @mcp.tool()
    def list_courses(grade: int | None = None, semester: int | None = None, category: str | None = None) -> str:
        """조건에 맞는 과목 목록을 반환합니다. 조건을 생략하면 해당 조건은 전체로 간주합니다.

        Args:
            grade: 학년 (1~4)
            semester: 학기 (1 또는 2)
            category: 이수구분. 교양필수, 교양선택, 전공필수, 전공선택, SW선택형전공필수 중 하나
        """
        if category and category not in CATEGORIES:
            return f"알 수 없는 이수구분입니다: {category}. 사용 가능한 값: {', '.join(CATEGORIES)}"
        hits = [c for c in COURSES
                if (grade is None or c["grade"] == grade)
                and (semester is None or c["semester"] == semester)
                and (category is None or c["category"] == category)]
        cond = " ".join(x for x in [f"{grade}학년" if grade else "", f"{semester}학기" if semester else "",
                                    category or ""] if x) or "전체"
        if not hits:
            return f"조건({cond})에 맞는 과목이 없습니다."
        total = sum(c["credits"] for c in hits)
        return f"조건({cond})에 맞는 과목 {len(hits)}개, 합계 {_num(total)}학점:\n" + "\n".join(_fmt(c) for c in hits)


    @mcp.tool()
    def credit_summary(grade: int | None = None, semester: int | None = None) -> str:
        """개설 과목 수와 학점 합계를 이수구분별로 집계합니다.
        이 값은 개설된 과목의 합계이며 졸업 이수 학점이 아닙니다.

        Args:
            grade: 학년 (1~4). 생략하면 전체 학년
            semester: 학기 (1 또는 2). 생략하면 전체 학기
        """
        hits = [c for c in COURSES
                if (grade is None or c["grade"] == grade) and (semester is None or c["semester"] == semester)]
        if not hits:
            return "조건에 맞는 과목이 없습니다."
        by = defaultdict(lambda: [0, 0.0])
        for c in hits:
            by[c["category"]][0] += 1
            by[c["category"]][1] += c["credits"]
        scope = " ".join(x for x in [f"{grade}학년" if grade else "", f"{semester}학기" if semester else ""] if x) or "전체"
        lines = [f"{scope}: 총 {len(hits)}개 과목, {_num(sum(c['credits'] for c in hits))}학점 (개설 과목 합계이며 졸업 학점 아님)"]
        lines += [f"- {k}: {v[0]}개 과목, {_num(v[1])}학점" for k, v in sorted(by.items())]
        return "\n".join(lines)


    if __name__ == "__main__":
        mcp.run(
            transport="streamable-http",
            host="0.0.0.0",
            port=int(os.environ.get("PORT", "8000")),
            stateless_http=True,
            json_response=True,
            # 클러스터 내부 Service DNS 이름으로 접근하므로 DNS rebinding 보호를 끕니다 (실습용)
            transport_security=TransportSecuritySettings(enable_dns_rebinding_protection=False),
        )

=== MCP 서버 동작 확인

모델을 연결하기 전에, 클라이언트가 MCP 서버와 주고받는 요청을 직접 보내 봅니다. MCP는 JSON-RPC 형식을 사용합니다.

. 서버 주소를 환경 변수로 저장합니다.
+
[source,bash,subs="attributes"]
----
export MCP_URL=http://curriculum-mcp.{mcp-namespace}.svc.cluster.local:8000/mcp
----

. 서버가 제공하는 도구 목록을 조회합니다(`tools/list`).
+
[source,bash]
----
curl -s $MCP_URL \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | jq -r '.result.tools[].name'
----
+
`search_courses`, `list_courses`, `credit_summary`가 출력되어야 합니다. 이 도구 목록과 설명이 그대로 모델에게 전달됩니다.

. 도구를 직접 실행합니다(`tools/call`). 3학년 전공필수 과목을 조회해 봅니다.
+
[source,bash]
----
curl -s $MCP_URL \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"list_courses","arguments":{"grade":3,"category":"전공필수"}}}' \
  | jq -r '.result.content[0].text'
----
+
다음과 같은 결과가 출력되어야 합니다.
+
[source,text]
----
조건(3학년 전공필수)에 맞는 과목 3개, 합계 9학점:
- 3학년 1학기 | 전공필수 | 컴퓨터구조 (COMPUTER ARCHITECTURE) | 3학점 | 강의 3시간, 실습 0시간
- 3학년 1학기 | 전공필수 | 컴퓨터네트워크 (COMPUTER NETWORKS) | 3학점 | 강의 3시간, 실습 0시간
- 3학년 2학기 | 전공필수 | 데이터베이스 (DATABASE) | 3학점 | 강의 3시간, 실습 0시간
----
+
image::mcp-curriculum/img-mcp-curl.png[curl로 MCP 도구를 호출한 결과]

TIP: `arguments` 값을 바꿔 가며 `search_courses`(예: `{"keyword":"딥러닝"}`)와 `credit_summary`(예: `{"grade":4}`)도 호출해 보세요. 이후 단계에서는 모델이 이와 똑같은 요청을 스스로 만들어 보냅니다.

== 단계 7.3: OpenShift AI에 MCP 서버 등록

MCP 서버를 배포했다고 해서 {productname-short}가 자동으로 찾아내지는 않습니다. Playground에서 사용할 MCP 서버는 `redhat-ods-applications` 네임스페이스의 `gen-ai-aa-mcp-servers` ConfigMap에 등록해야 하며, 등록된 서버가 *AI asset endpoints*의 MCP 서버 목록에 표시됩니다.

[cols="1,2,2",options="header"]
|===
| 구분 | 위치 | 역할

| MCP 서버 (Pod, Service)
| `{mcp-namespace}` (어느 프로젝트든 가능)
| 실제로 도구를 실행하는 서버

| `gen-ai-aa-mcp-servers` ConfigMap
| `redhat-ods-applications` (고정)
| {productname-short}에 "이런 MCP 서버가 있다"고 알려주는 목록
|===

. WebTerminal에서 다음 명령을 실행하여 MCP 서버를 등록합니다. 이미 다른 MCP 서버가 등록되어 있다면 기존 항목은 유지하고 새 항목만 추가합니다.
+
[source,bash,subs="attributes"]
----
NS=redhat-ods-applications
CM=gen-ai-aa-mcp-servers
ENTRY='{"url":"http://curriculum-mcp.{mcp-namespace}.svc.cluster.local:8000/mcp","description":"인공지능공학전공 교육과정(학년/학기별 과목, 이수구분, 학점) 조회 도구"}'

if oc get configmap $CM -n $NS >/dev/null 2>&1; then
  oc set data configmap/$CM -n $NS Curriculum-MCP-Server="$ENTRY"
else
  oc create configmap $CM -n $NS --from-literal=Curriculum-MCP-Server="$ENTRY"
fi
----

. 등록된 내용이 올바른 JSON 형식인지 확인합니다.
+
[source,bash]
----
oc get configmap gen-ai-aa-mcp-servers -n redhat-ods-applications \
  -o jsonpath='{.data.Curriculum-MCP-Server}' | jq .
----
+
`url`과 `description`이 출력되면 정상입니다. `parse error`가 나오면 JSON 형식이 잘못된 것이므로 1번 명령을 다시 실행합니다.

. {productname-short} 대시보드에서 *Gen AI studio* > *AI asset endpoints*로 이동하여, *MCP servers* 목록에 `Curriculum-MCP-Server`가 표시되는지 확인합니다.
+
image::mcp-curriculum/img-mcp-asset-endpoints.png[AI asset endpoints에 표시된 Curriculum-MCP-Server]
+
목록에 보이지 않으면 브라우저를 새로고침합니다. 그래도 보이지 않으면 다음 명령으로 대시보드를 재시작한 뒤 1~2분 후 다시 확인합니다.
+
[source,bash]
----
oc rollout restart deployment/rhods-dashboard -n redhat-ods-applications
----

NOTE: ConfigMap 형식이 잘못되면 Playground가 정상적으로 시작되지 않을 수 있습니다. 반드시 2번의 `jq` 확인을 통과한 뒤 다음 단계로 진행하세요.


== 단계 7.2: 모델에 도구 호출(Tool Calling) 기능 활성화

MCP 도구를 사용하려면 모델이 "어떤 도구를 어떤 인자로 호출할지"를 정해진 형식으로 응답할 수 있어야 합니다. 이를 *도구 호출(tool calling)* 이라고 하며, vLLM은 기본적으로 이 기능이 꺼져 있습니다. 따라서 모델 배포 시 다음 두 인자를 추가해야 합니다.

[cols="1,2",options="header"]
|===
| 인자 | 역할

| `--enable-auto-tool-choice`
| 모델이 질문에 따라 도구 사용 여부를 스스로 판단하도록 허용합니다.

| `--tool-call-parser=gemma4`
| 모델이 생성한 텍스트에서 도구 호출 부분을 찾아 OpenAI API 형식(`tool_calls`)으로 변환합니다. 모델마다 출력 형식이 달라 모델에 맞는 파서를 지정해야 합니다.
|===
