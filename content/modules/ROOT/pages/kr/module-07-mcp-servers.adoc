= Playground 및 MCP 연결

이 모듈에서는 앞에서 MaaS로 서비스한 모델을 OpenShift AI에서 제공하는 Playground에 연결하고, 학과 교육과정을 조회하는 MCP(Model Context Protocol) 서버를 도구로 추가합니다. 모델이 학습하지 않은 정보도 외부 도구를 호출해 정확하게 답하는 과정을 직접 확인합니다.

이 모듈을 완료하면 다음을 갖추게 됩니다:

* Playground에 연결된 MaaS 모델
* 학과 교육과정을 조회하는 MCP 도구가 연결된 에이전트
* MCP 도구 사용 전후의 답변 차이에 대한 이해

== 단계 7.1: 사전 배포된 MCP 서버 확인
이번 실습에서 사용할 MCP 서버는 클러스터의 `mcp-servers` 프로젝트에 미리 배포되어 있습니다. 이 서버는 인공지능공학전공 교육과정 데이터(61개 과목)를 읽어 다음 세 가지 도구를 제공합니다.

. 등록된 내용을 확인합니다.
+
[source,bash]
----
oc get configmap gen-ai-aa-mcp-servers -n redhat-ods-applications \
  -o jsonpath='{.data.Curriculum-MCP-Server}' | jq .
----
+
`url`이 앞에서 호출한 `MCP_URL`과 같은 주소인지 확인합니다. 아래 그림에서 view를 눌러서 확인할 수 있습니다.

. 대시보드에서 *Gen AI studio* > *AI asset endpoints*로 이동하여, *MCP servers* 목록에 `Curriculum-MCP-Server`가 표시되는지 확인합니다.
+
image::mcp-servers/img-mcp-servers-1.png[AI asset endpoints에 표시된 Curriculum-MCP-Server]


== 단계 7.2: 모델에 도구 호출(Tool Calling) 기능 활성화

MCP 도구를 사용하려면 모델이 "어떤 도구를 어떤 Arguements로 호출할지"를 정해진 형식으로 응답할 수 있어야 합니다. 이를 *도구 호출(tool calling)* 이라고 하며, vLLM은 기본적으로 이 기능이 꺼져 있습니다. 따라서 모델 배포 시 다음 두 Arguements를 추가해야 합니다.

[cols="1,2",options="header"]
|===
| 인자 | 역할

| `--enable-auto-tool-choice`
| 모델이 질문에 따라 도구 사용 여부를 스스로 판단하도록 허용합니다.

| `--tool-call-parser=gemma4`
| 모델이 생성한 텍스트에서 도구 호출 부분을 찾아 OpenAI API 형식(`tool_calls`)으로 변환합니다. 모델마다 출력 형식이 달라 모델에 맞는 파서를 지정해야 합니다.
|===

NOTE: 이 인자가 없으면 모델은 에러 없이 도구를 무시하고 텍스트로만 답합니다. 도구가 호출되지 않는다면 가장 먼저 이 설정을 확인하세요.

. 대시보드에서 *AI hub* > *Models* > *Deployments*로 이동하고 본인의 프로젝트를 선택합니다.
. 배포된 모델의 오른쪽 메뉴(⋮)를 클릭하고 *Edit*을 선택합니다.
+
image::mcp-servers/img-mcp-servers-2.png[배포된 모델의 메뉴에서 Edit 선택]

. *Next*를 눌러서 *3 Advanced settings*의 *Configuration parameters* 부분의 *Add custom runtime arguments*를 체크한 후, *두 개의 Argument*를 추가합니다.
+
[source,text]
----
--enable-auto-tool-choice
--tool-call-parser=gemma4
----
+
image::mcp-servers/img-mcp-servers-3.png[Tool Calling 기능 활성화]

. 모델 재 배포가 완료될 때까지 기다립니다. 다음과 같이 Running 상태로 표시되면 다음 단계를 진행할 수 있습니다.
image::mcp-servers/img-mcp-servers-4.png[모델 배포 확인]

== 단계 7.3: Plyground 실행
Playground는 OpenShift AI에서 제공하는 대화형 테스트 환경으로, 배포한 모델과 채팅하고 MCP 서버 같은 외부 도구를 연결해 볼 수 있습니다. 이 단계에서는 먼저 *도구 없이* 모델과 대화한 뒤, *MCP 서버를 연결*하여 같은 질문의 답변이 어떻게 달라지는지 비교합니다.

[source,text]
----
 사용자 ──질문──▶ Playground
                     │  ① 질문 + MCP 도구 목록 전달
                     ▼
                  모델 (Gemma)
                     │  ② "list_courses(grade=3, category='전공필수')를 호출해 줘"
                     ▼
                 Playground ──③ 도구 실행──▶ MCP 서버 (curriculum-mcp)
                     │  ④ 실행 결과를 모델에 다시 전달
                     ▼
                  모델 ──⑤ 결과를 근거로 최종 답변 생성──▶ 사용자
----
 
=== Playground 생성
. OpenShift AI Console 대시보드에서 *Gen AI studio* > *Playground*로 이동합니다.
. 상단에서 모델을 배포한 프로젝트를 선택합니다.
. Playground가 아직 없다면 *Create playground*를 클릭합니다.
+
image::mcp-servers/img-playground-1.png[Playground 생성 화면]

. 사용할 모델로 앞에서 배포한 모델(예: `RedHatAI/gemma-4-E4B-it`)을 선택하고 *Create*를 클릭합니다.
+
image::mcp-servers/img-playground-2.png[Playground에 사용할 모델을 선택하는 화면]

. Playground가 준비될 때까지 기다립니다. 처음 생성할 때는 관련 구성 요소가 프로젝트에 배포되므로 1~2분 정도 걸릴 수 있습니다.
+
NOTE: 생성 중에 화면이 계속 로딩 상태라면 WebTerminal에서 `oc get pods -n <프로젝트>`를 실행하여 `lsd-genai-playground`로 시작하는 Pod가 `Running`인지 확인합니다.
