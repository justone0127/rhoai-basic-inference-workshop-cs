= 소개

본 워크숍은 OpenShift AI 3.5에서 AI 모델 추론을 배포하고 테스트하는 실습 가이드입니다. 모델 카탈로그에서 모델을 배포하고, 계층화된 접근 방식의 Model-as-a-Service (MaaS)를 구성한 후, 채팅 인터페이스를 설정하여 엔드투엔드 추론을 테스트합니다.

[TIP]
====
스크립트를 통한 환경 설정(MaaS 게이트웨이, Operator, 대시보드 기능, DevSpaces 등)은 https://github.com/jingggg-wenn/rhoai-sno-setup-guide[RHOAI 3.5 SNO Setup Guide]를 참조하십시오. 두 개의 스크립트로 전체 클러스터 준비를 자동화할 수 있습니다.
====

== 학습 목표

본 워크숍을 완료하면 다음을 수행할 수 있습니다:

* {productname-short}에서 Data Science 프로젝트를 생성합니다
* 모델 카탈로그에서 llm-d 서빙 런타임을 사용하여 AI 모델을 배포합니다
* 서로 다른 토큰 속도 제한(Premium 및 Basic 등급)으로 MaaS 구독을 구성합니다
* 인증된 모델 접근을 위한 API 키를 생성합니다
* 자체 호스팅 채팅 인터페이스인 Open WebUI를 배포합니다
* MaaS 게이트웨이를 통해 Open WebUI를 모델에 연결하고 채팅 기반 추론을 테스트합니다

== 사전 요구 사항

시작하기 전에 다음 사항을 확인하십시오:

* {rhoai-short} {rhoai-version}이 설치된 {ocp} 클러스터가 실행 중이어야 합니다
* 클러스터에 GPU 노드가 하나 이상 사용 가능해야 합니다 (예: NVIDIA L4, L40S, A100)
* 관리자가 GPU Hardware Profile을 생성해 두어야 합니다
* 강사가 제공한 로그인 자격 증명(사용자명 및 비밀번호)이 준비되어 있어야 합니다

== 사용자 계정 안내

본 가이드에서는 `user-XX` 또는 `admin-XX`와 같은 형식이 사용됩니다. `XX`를 배정받은 번호로 교체하십시오.

예를 들어, *user 5*로 배정받은 경우:

* `user-XX`는 `user-05`가 됩니다
* 프로젝트 이름은 `user-05`입니다

항상 두 자리 숫자를 사용하십시오: user05 = `user-05`, admin02 = `admin-02`.
