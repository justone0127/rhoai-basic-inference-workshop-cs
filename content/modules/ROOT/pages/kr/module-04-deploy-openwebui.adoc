[#deploy-openwebui-kr]
= Open WebUI 배포

이 모듈에서는 ChatGPT와 유사한 자체 호스팅 채팅 인터페이스인 Open WebUI를 배포합니다. 모든 명령줄 작업은 OpenShift Web Terminal을 사용합니다.

== 단계 4.1: Web Terminal 열기

. OpenShift AI 대시보드 우측 상단의 격자 아이콘(3x3 사각형)을 클릭하여 **OpenShift Console**에 접속합니다.
. OpenShift Console 우측 상단의 **>_** 아이콘을 클릭하여 Web Terminal을 엽니다.

브라우저 안에서 동작하는 터미널이 열리며, `oc`, `git`, `sed`가 미리 설치되어 있습니다. 로컬 PC에 CLI 도구를 설치할 필요는 없습니다.

== 단계 4.2: 워크숍 리포지토리 복제

[source,sh,role="execute"]
----
git clone https://github.com/justone0127/rhoai-basic-inference-workshop-cs.git
----

[source,sh,role="execute"]
----
cd rhoai-basic-inference-workshop-cs
----

== 단계 4.3: 환경 변수 설정

본인의 네임스페이스를 설정합니다. `user-XX` 부분을 본인의 네임스페이스로 변경한 후 실행합니다(예: `user-05` 또는 `admin-02`).

[source,sh,role="execute"]
----
export NAMESPACE=user-XX
----

== 단계 4.4: Open WebUI 배포

Open WebUI는 네임스페이스에 다음 리소스를 배포합니다.

* **ConfigMap**: Open WebUI의 기본 설정
* **PersistentVolumeClaim**: Open WebUI 데이터용 2Gi 스토리지
* **Deployment**: Open WebUI 컨테이너
* **Service**: 클러스터 내부에서 접근하기 위한 8080 포트
* **Route**: 브라우저에서 접근하기 위한 외부 HTTPS URL

``NAMESPACE`` 변수가 설정되어 있고 현재 위치가 워크숍 리포지토리 디렉터리인지 확인한 후 배포합니다.

[source,sh,role="execute"]
----
sed "s/\${NAMESPACE}/$NAMESPACE/g" manifests/open-webui.yaml | oc apply -f -
----

== 단계 4.5: Open WebUI 배포 완료 대기

[source,sh,role="execute"]
----
oc rollout status deployment/open-webui -n $NAMESPACE --timeout=120s
----

``deployment "open-webui" successfully rolled out``이 출력되면 배포가 완료된 것입니다.

== 단계 4.6: Open WebUI URL 확인

[source,sh,role="execute"]
----
echo "https://$(oc get route open-webui -n $NAMESPACE -o jsonpath='{.spec.host}')"
----

OpenShift Console에서도 URL을 확인할 수 있습니다. 본인의 프로젝트를 선택한 후 **Networking** > **Routes** > `open-webui`로 이동합니다.

image::openwebui/img-ocp-route-openwebui.png[OpenShift Console에 표시된 Open WebUI 경로]

이 URL을 복사하여 브라우저에서 엽니다.

image::openwebui/img-openwebui-default.png[Open WebUI 기본 랜딩 페이지]

Open WebUI가 실행되면, 모듈 5에서 MaaS API 키를 생성한 후 모듈 6에서 모델을 연결합니다.
