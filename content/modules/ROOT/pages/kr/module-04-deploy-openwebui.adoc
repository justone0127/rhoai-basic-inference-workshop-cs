[#deploy-openwebui-kr]
= Open WebUI 배포 및 모델 연결

이 모듈에서는 ChatGPT와 유사한 자체 호스팅 채팅 인터페이스인 Open WebUI를 배포하고 모델에 연결합니다. 모든 명령줄 작업은 {ocp-short} Web Terminal을 사용합니다.

== 단계 4.1: Web Terminal 열기

. {productname-short} 대시보드 우측 상단의 격자 아이콘(3x3 사각형)을 클릭하여 *{ocp-short} Console*에 접속합니다.
. {ocp-short} Console 우측 상단의 *>_* 아이콘을 클릭하여 Web Terminal을 엽니다.

브라우저 내 터미널이 제공되며, `oc`, `git`, `sed`가 사전 설치되어 있습니다. 로컬 CLI 도구는 필요하지 않습니다.

== 단계 4.2: 워크숍 리포지토리 복제

[source,sh,role="execute"]
----
git clone https://github.com/justone0127/rhoai-basic-inference-workshop-cs.git
----

[source,sh,role="execute"]
----
cd rhoai-basic-inference-workshop
----

== 단계 4.3: 환경 변수 설정

본인의 네임스페이스를 설정합니다 (예: `user-05` 또는 `admin-02`):

[source,sh,role="execute"]
----
export NAMESPACE=user-XX
----

== 단계 4.4: Open WebUI 배포

Open WebUI는 네임스페이스에 다음 리소스를 배포합니다:

* *ConfigMap* -- Open WebUI의 기본 설정
* *PersistentVolumeClaim* -- Open WebUI 데이터용 2Gi 스토리지
* *Deployment* -- Open WebUI 컨테이너
* *Service* -- 포트 8080의 클러스터 내부 접근
* *Route* -- 브라우저 접근을 위한 외부 HTTPS URL

`NAMESPACE` 변수가 설정되어 있고 워크숍 리포지토리 디렉터리에 있는지 확인한 후 배포합니다:

[source,sh,role="execute"]
----
sed "s/\${NAMESPACE}/$NAMESPACE/g" manifests/open-webui.yaml | oc apply -f -
----

== 단계 4.5: Open WebUI 대기

[source,sh,role="execute"]
----
oc rollout status deployment/open-webui -n $NAMESPACE --timeout=120s
----

== 단계 4.6: Open WebUI URL 확인

[source,sh,role="execute"]
----
echo "https://$(oc get route open-webui -n $NAMESPACE -o jsonpath='{.spec.host}')"
----

OpenShift Console에서도 URL을 확인할 수 있습니다: *Networking* > *Routes* > `open-webui`.

image::openwebui/img-ocp-route-openwebui.png[OpenShift Console에 표시된 Open WebUI 경로]

이 URL을 복사하여 브라우저에서 엽니다.

image::openwebui/img-openwebui-default.png[Open WebUI 기본 랜딩 페이지]

Open WebUI가 실행되면, 모듈 5에서 MaaS API 키를 설정한 후 모듈 6에서 모델을 연결합니다.
